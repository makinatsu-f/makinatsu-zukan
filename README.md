
この図鑑について

この図鑑は、マキナツがアップリケバッグを制作する中で調べたり、知ったりした生き物のことを、楽しく紹介するWeb図鑑です。

生き物の専門家が作る図鑑のように、専門的な内容を詳しく紹介することを目的としていません。

「もっと知りたい！」「またやりたい！」

そんなふうに、生き物に興味を持つきっかけになったら嬉しいな、という思いで作っています。

※内容についてお気づきの点がありましたら、ぜひ教えてください。
